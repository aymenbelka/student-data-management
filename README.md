# نظام إدارة بيانات الطلاب

تطبيق عربي متكامل لإدارة طلاب المرحلة الابتدائية والمتوسطة، مبني باستخدام PHP وSQLite وHTML/CSS/JavaScript.

## المزايا
- إضافة بيانات الطالب: الاسم، العنوان، الهاتف، المرحلة، الصف، ولي الأمر، تاريخ الميلاد والملاحظات.
- عرض قائمة الطلاب مع إحصائيات المراحل.
- البحث الفوري بالاسم أو الهاتف أو العنوان أو ولي الأمر.
- تصفية حسب المرحلة.
- تعديل وحذف البيانات مع تأكيد قبل الحذف.
- تصميم عربي متجاوب مع الهاتف والحاسوب.
- قاعدة بيانات SQLite تُنشأ تلقائياً داخل `data/students.sqlite`.
- API CRUD باستخدام PDO والاستعلامات المجهزة.

## التشغيل محلياً
يتطلب PHP 8 أو أحدث مع تفعيل `pdo_sqlite`:

```bash
php -S localhost:8000
```
ثم افتح: http://localhost:8000

يجب أن يملك PHP صلاحية الكتابة على مجلد المشروع لإنشاء مجلد `data` وقاعدة البيانات.

## النشر
يمكن نشره على أي استضافة تدعم PHP 8 وSQLite. ارفع الملفات، وتأكد من صلاحية الكتابة لمجلد `data`. لا تجعل ملف قاعدة البيانات متاحاً للتنزيل عبر الويب؛ يمكن إضافة قاعدة إلى إعدادات الاستضافة لمنع الوصول إلى مجلد `data`.

> ملاحظة أمنية: قبل استخدام النظام في مدرسة حقيقية، أضف نظام تسجيل دخول وصلاحيات ونسخاً احتياطية دورية، لأن بيانات الطلاب معلومات شخصية حساسة.
